In my recent project FoolishStoreMobile, I developed a mobile application for a fashion retail store where users can browse product catalogues, add items to their cart, 
and complete checkout. I implemented user authentication so customers can log in/register, used a RESTful API to fetch product data and order status, and designed a 
responsive UI with image-rich product cards to enhance the shopping experience. One of the biggest challenges was optimizing the product list to load smoothly with large 
images, so I implemented asynchronous image loading and caching to reduce lag. Through this project, I gained hands-on experience in mobile UI/UX design, API integration, 
and state management for e-commerce workflows.
